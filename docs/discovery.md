# Configless discovery contract

Decisions before implementation, 0.2.0:

- No selected config: collect local metrics and discover the current tailnet with `tailscale status --json`. No installation or login to Tailscale is performed. Unavailable/invalid discovery keeps the local result and reports incomplete remote coverage.
- Config precedence: `--config` > `TSLS_CONFIG` > XDG/default user path. Only an absent implicit default file enables discovery; unreadable or malformed files and missing explicitly selected files are usage errors. Existing configs keep their explicit host set. `--discover` bypasses all tsls config, including TSLS_CONFIG; combining it with --config is a usage error. Flags > timing env vars > config > defaults. `init` remains optional and creates an explicit local-only set.
- `--discover` and `--strict` are the only new flags. Default discovery returns 0 if the local probe succeeds; remote inaccessibility or expected skips remain visible as incomplete coverage. Explicit configuration/positional selection and --strict require all selected rows to succeed. Missing discovery is incomplete under --strict. 1 = runtime/incomplete required coverage; 2 = invalid usage/config; 130 = user cancellation. Failed local collection always returns 1.
- Query only peers from the official JSON interface. Deduplicate Self/Peer by stable ID. Skip offline, unsupported or unknown OS peers without SSH. Retain skipped records with reasons. Supported remote OS: Linux and macOS/Darwin. Sanitize labels and disambiguate collisions. Direct access prefers a validated Tailscale IP, then DNS or a safe hostname; DNS remains available for matching SSH aliases. This avoids depending on client MagicDNS.
- Unix accounts are never inferred from Tailscale ownership or OS. Prefer literal aliases found in standard user/system SSH configs and Includes whose effective `ssh -G` hostname matches the peer. Otherwise pass its validated destination to OpenSSH, which owns login/identity defaults; failure is unavailable coverage, not a guess/retry with another Unix user. User config is trusted executable OpenSSH configuration. No new trust entries, credentials, root commands or agents.
- Limits: 32 total probes including local, 30 seconds for discovery/mapping/collection, 3 seconds and 4 MiB for Tailscale, 5 seconds for alias resolution, at most 100 literal SSH aliases and 16 config files. Per-host timeout defaults to 5s, concurrency to 4. Every peer beyond a limit remains in JSON with a reason; discovery/mapping diagnostics disclose bounded or unavailable coverage.
- JSON schemaVersion 2 explicitly adds discovery, coverage, peer metadata and skipped status/reasons. Byte/source/quality formulas and null semantics remain unchanged. TSV retains its columns and adds skipped rows/reason codes; consumers must accept new status/error codes in 0.2.0. Human output lists readings and a short summary of skip/failure reasons. stdout remains data, stderr bounded diagnostics. No raw SSH stderr or addresses in error messages.
- Cancellation kills process groups. A deadline retains completed results and represents unstarted probes as skipped. Snapshot completion does not assert simultaneous metrics. Actual tailnet data and SSH mappings stay outside the public repository.
